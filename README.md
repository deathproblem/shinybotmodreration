# 🛡️ Telegram Moderator Bot (Анти-ссылки, Анти-мат, Анти-спам)

Современный асинхронный Telegram-бот на Python 3.11+ и **aiogram 3.x** для автоматической модерации групп и супергрупп.

---

## ⚡ Возможности

1. **🔗 Блокировка любых ссылок (Anti-Link)**:
   - Обнаруживает кликабельные сущности Telegram (`URL`, `TEXT_LINK` в Markdown/HTML).
   - Ловит любые доменные зоны (`.com`, `.ru`, `.xyz`, `.top` и др.), ссылки `t.me/`, протоколы (`http://`, `https://`, `tg://`).
   - Распознает замаскированные ссылки (например, `site[.]ru`, `mysite dot ru`, `domain(.)com`).
   - Администраторы могут публиковать ссылки (настраивается в `.env`).

2. **🤬 Продвинутый мат-фильтр (Anti-Profanity)**:
   - Защита от обхода маскировкой: латиница вместо кириллицы (homoglyphs: `cукa`), цифры и символы (`х0й`, `@`, `$`), точки и тире внутри слов (`п.и.з.д.е.ц`), пробелы между буквами (`б л я т ь`).
   - Сжатие повторяющихся символов (`суууука` -> `сука`).
   - Белый список исключений для предотвращения ложных срабатываний (*рубль, употреблять, колебания, страхование, шахматы* и т.д.).

3. **🚫 Анти-спам и анти-флуд (Anti-Spam & Anti-Flood)**:
   - **Рейт-лимит (троттлинг)**: блокировка частой отправки сообщений (по умолчанию: не более 4 сообщений за 4 секунды).
   - **Анти-капс**: удаление сообщений, написанных CAPS LOCK (>70% заглавных букв).
   - **Анти-реклама**: блокировка пересылок постов из других каналов.
   - **Защита от спам-тегов**: блокировка массовых упоминаний (`@user1 @user2...`).

4. **⚠️ Система предупреждений (варнов)**:
   - Автоматическое удаление сообщения нарушителя.
   - Уведомление в чат с причиной нарушения и таймером **авто-удаления через 8 секунд** (чат не засоряется!).
   - По умолчанию: при получении **3 предупреждений** бот выдает нарушителю **мут на 24 часа**.
   - SQLite база данных (предупреждения сохраняются при перезапуске бота).

5. **👑 Админ-команды в чате**:
   - `/warn [причина]` — выдать предупреждение пользователю (в ответ на сообщение).
   - `/unwarn` — снять одно предупреждение.
   - `/warns` — проверить количество предупреждений пользователя.
   - `/mute [время]` — замутить пользователя (например: `/mute 15m`, `/mute 2h`, `/mute 1d`).
   - `/unmute` — снять мут.
   - `/ban` — навсегда забанить в группе.
   - `/unban <user_id>` — разбанить.

## 🛠️ Быстрый старт (Локально)

### 1. Получение токена бота
1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте команду `/newbot`.
2. Укажите имя и username для бота.
3. Скопируйте полученный **API токен** (вида `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`).

### 2. Настройка проекта
1. Склонируйте или откройте папку проекта:
   ```bash
   cd telegram-moderator-bot
   ```
2. Скопируйте `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
3. Откройте файл `.env` и вставьте ваш токен:
   ```env
   BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   ```

### 3. Запуск бота
```bash
# Создание виртуального окружения
python -m venv venv

# Активация окружения (Windows PowerShell)
.\venv\Scripts\Activate.ps1
# (или в Linux/macOS: source venv/bin/activate)

# Установка зависимостей
pip install -r requirements.txt

# Запуск бота
python main.py
```

## 🌐 Установка и запуск на Сервере (VPS / VDS)

Для круглосуточной работы бота лучше всего развернуть его на виртуальном сервере (например, Timeweb Cloud, Aeza, Beget, Selectel, FirstVDS) под управлением Linux (Ubuntu 22.04 / 24.04).

### Вариант 1. Развертывание через Docker (Рекомендуется)

Самый быстрый и изолированный способ:

1. Установите Docker и Docker Compose на сервере (если еще не установлены):
   ```bash
   curl -fsSL https://get.docker.com | sh
   ```
2. Скопируйте папку проекта на сервер (через `git clone` или `scp`).
3. Перейдите в папку проекта:
   ```bash
   cd telegram-moderator-bot
   ```
4. Создайте и заполните `.env`:
   ```bash
   nano .env
   ```
   *(Вставьте ваш `BOT_TOKEN` и сохраните: Ctrl+O, Enter, Ctrl+X)*
5. Запустите бота одной командой:
   ```bash
   docker compose up -d --build
   ```

**Полезные команды Docker:**
- Посмотреть статус и логи: `docker compose logs -f`
- Перезапустить бота: `docker compose restart`
- Остановить бота: `docker compose down`

---

### Вариант 2. Развертывание как системная служба (systemd)

Если вы запускаете бота напрямую на сервере без Docker:

1. Скопируйте проект в директорию `/opt/telegram-moderator-bot`:
   ```bash
   sudo mkdir -p /opt/telegram-moderator-bot
   sudo cp -r . /opt/telegram-moderator-bot/
   cd /opt/telegram-moderator-bot
   ```
2. Установите зависимости:
   ```bash
   python3 -m venv venv
   ./venv/bin/pip install -r requirements.txt
   ```
3. Настройте файл конфигурации:
   ```bash
   nano .env
   ```
4. Скопируйте файл службы:
   ```bash
   sudo cp bot.service /etc/systemd/system/moderator-bot.service
   sudo systemctl daemon-reload
   sudo systemctl enable --now moderator-bot
   ```
5. Проверка работы:
   ```bash
   sudo systemctl status moderator-bot
   # Просмотр логов в реальном времени:
   journalctl -u moderator-bot -f
   ```

## 👥 Настройка бота в группе Telegram

1. Добавьте вашего бота в Telegram-группу (супергруппу).
2. Перейдите в **Управление группой** $\rightarrow$ **Администраторы** $\rightarrow$ **Добавить администратора**.
3. Выберите вашего бота и обязательно включите следующие права:
   - ✅ **Удаление сообщений (Delete Messages)** — чтобы бот мог удалять спам, мат и ссылки.
   - ✅ **Блокировка пользователей (Ban/Restrict Users)** — чтобы бот мог выдавать мут и бан нарушителям.
   - ✅ **Закрепление сообщений** (опционально).
4. Готово! Теперь любое сообщение с ссылкой, матом или спамом будет немедленно удалено, а нарушитель получит предупреждение.

## ⚙️ Параметры конфигурации (`.env`)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | Токен бота от `@BotFather` |
| `ENABLE_LINK_FILTER` | `True` | Включение фильтра ссылок |
| `ENABLE_PROFANITY_FILTER` | `True` | Включение фильтра нецензурной лексики |
| `ENABLE_SPAM_FILTER` | `True` | Включение фильтра спама и капслока |
| `ENABLE_FLOOD_FILTER` | `True` | Включение защиты от частого флуда |
| `ALLOW_ADMINS_BYPASS` | `True` | Разрешать администраторам чата слать ссылки и обходить фильтры |
| `MAX_WARNINGS` | `3` | Количество предупреждений до выдачи мута |
| `MUTE_DURATION_HOURS` | `24` | Длительность мута в часах при достижении лимита |
| `FLOOD_MESSAGE_LIMIT` | `4` | Максимум сообщений за промежуток времени |
| `FLOOD_TIME_SECONDS` | `4` | Окно времени для антифлуда (в секундах) |
| `AUTO_DELETE_ALERT_SECONDS` | `8` | Время жизни служебных сообщений бота в чате |
